About QuickNotes

QuickNotes is a simple way to capture your thoughts, organize important information, and find it when you need it.

How to use QuickNotes

  1. Open QuickNotes and choose to create a new note.
  2. Give your note a clear title.
  3. Write down your ideas or information.
  4. Save the note so you can return to it later.

Key Features

  • Instant, offline-first note creation - zero loading screens
  • Full-text search across all notes, including tags
  • Attach images, links and code snippets

Keyboard shortcuts

Action Shortcut (Windows / Linux) Shortcut (macOS)
New Note Ctrl + N Cmd + N
Save Note Ctrl + S Cmd + S
Search Notes Ctrl + F Cmd + F
Toggle preview Ctrl + P Cmd + P
